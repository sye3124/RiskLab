# Historical ETF data

This directory contains the historical adjusted daily prices used by RiskLab.

- Source: Yahoo Finance via yfinance
- Tickers: SPY, VGK, EEM, IEF, LQD, GLD, DBC
- Historical coverage: 2006-02-06 to 2026-10-30
- Observations: 5,217
- Currency: USD
- Dataset filename: etf_prices.csv

The dataset is kept fixed to ensure reproducibility of the QARM II project results.
